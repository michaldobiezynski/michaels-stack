# ELI5

Explain the input so a five-year-old would follow it.

## Input

1. If arguments were given, explain that topic or rewrite that text.
2. If no arguments were given, rewrite your previous answer in this conversation.
3. When chained after another skill or command, treat that command's output as the input.

## Style

- Very short: three to six small sentences.
- Only words a small child knows. No jargon at all, and no numbers beyond tiny ones ('lots', 'a few').
- Build the whole explanation around one familiar thing: toys, snacks, pets, playgrounds, family.
- Warm and playful, never condescending.
- Honest: leaving things out is fine; getting things wrong is not.

## Output

Only the explanation itself, no preamble. British English.
